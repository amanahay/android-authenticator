# Privacy Policy — Amanah Authenticator

Effective date: 24 August 2026

Amanah Authenticator is a free, offline-first TOTP authenticator. Account secrets are stored only in encrypted storage on the user's Android device. The application does not collect analytics, use advertising SDKs, transmit account secrets to the developer, or create an account.

When a user explicitly exports a backup, the user chooses its destination using Android's system file picker. The user may choose Google Drive or another provider. The application does not access Google Drive, Google accounts, or any cloud account automatically in this release.

Users are responsible for protecting their device and backups. A backup can contain TOTP secrets and must not be shared.
